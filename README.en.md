# Arithprac: Arithmetic Worksheet Generator

[日本語](README.md)

A tool that automatically generates arithmetic practice worksheets (PDF files) for preschool and elementary school children.

More people are probably interested in the generated worksheets than in the tool itself, so this README describes the worksheets.

## Introduction

This is essentially just a public release of the worksheets I have my own children do, so breaking changes may land without warning (the format of the published worksheets may change without notice).

I take no responsibility whatsoever for anything that results from using the worksheets or the program, or for the worksheets suddenly no longer being provided. Please understand this in advance.

As long as my automatic generation system is working, the PDF files are updated once a day at night in JST, and both the latest file and the one before it are published.

The MIT License applies to this program and to the arithmetic worksheets (PDF files) generated by it and hosted on GitHub (excluding the embedded fonts), so you are free to copy, print and distribute the files at no cost.
