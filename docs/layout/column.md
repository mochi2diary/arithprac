# 問題(筆算) のレイアウト

役割: 筆算形式の問題面レイアウト。用紙・共通事項および解答面は [CLAUDE.md](../../CLAUDE.md) / [answer.md](answer.md) を参照。

## ページ・用紙

問題(暗算)と同一。

## A5 1枚(1回分)の構成 — `probset(title, left, right)`

上から順に:

1. **大見出し**: 中央揃え，18pt，太字(`weight: "bold"`)。文言は「筆算マスター」。
2. `#v(3pt)` の空き。
3. **回・名前・得点の行**: 問題(暗算)と同様。
4. `#v(12pt)` の空き。
5. **問題本体**: 見出し以降の残り領域を，格子状の「リージョン」に等分割し，1 リージョンに 1 問を配置する。

## リージョン割り

- 問題(筆算)では，問題本体用の領域をリージョンに分割し，1リージョンに1問を配置する。リージョン間に空白は発生しないようにする。
- 1回あたりのリージョン数(= 問題数)は `-n` `--num N`(N: Integer) で指定し，`N` は 12 / 8 / 6 / 4 / 1 のいずれかとする。分割形は `N` により一意に定まる。筆算の各ステージでは `--num` 相当の指定を行う。
    - `12`: 縦4個 × 横3列
    - `8`: 縦4個 × 横2列
    - `6`: 縦3個 × 横2列
    - `4`: 縦2個 × 横2列
    - `1`: 分割せず，1問が残り領域の全体を占有する
- 分割は `grid` による等分とする。`columns` は列数分の `1fr`，`rows` は行数分の `1fr`，`align: center + horizon`(各リージョンの中央に問題を置く)。
- リージョンの区切り線: 列の間に縦の点線 `grid.vline(...)`，行の間に横の点線 `grid.hline(...)` を引く。いずれも `dash: "dotted"`，色 `luma(140)`，太さ 0.4pt とする。
    - 外周(最上・最下・最左・最右)には線を引かず，リージョン間の境界にのみ引く。
- 問題番号(丸数字)の割り当て順は行優先(各行を左→右，行は上→下)。
- リージョン内の文字サイズ・筆算の桁幅は `--scale`(`small` / `medium` / `large`)で決まり，リージョン割りとは独立した設定とする(具体値は TBD)。

## リージョン内のレイアウト

リージョン内のレイアウトは，筆算の種別によって異なる。

### 筆算(たしざん)

- 問題は1文字=1セルを基本とし `grid` で組む。セル間に空白は発生しないようにする。
- 最上行から，被加数行，加数行，横線行，解答記入行とする。1行=縦1セルとする。
    - `--scale` 指定に従い，セルの高さ・幅および中の文字サイズ等を決定する。
        - 被加数行:
            - `small`: セルは横 4.8mm × 縦 7.2mm，文字サイズ 14pt(上下左右中央揃え)
            - `medium`: セルは横 6mm × 縦 9.6mm，文字サイズ 16pt(上下左右中央揃え)
            - `large`: セルは横 6.9mm × 縦 10.8mm，文字サイズ 18pt(上下左右中央揃え)
        - 加数行:
            - `small`: セルは横 4.8mm × 縦 6mm，文字サイズ 14pt(上下左右中央揃え)
            - `medium`: セルは横 6mm × 縦 7.5mm，文字サイズ 16pt(上下左右中央揃え)
            - `large`: セルは横 6.9mm × 縦 9mm，文字サイズ 18pt(上下左右中央揃え)
        - 横線行: 以下のセルサイズとする。
            - `small`: セルは横 4.8mm × 縦 0.5mm，線の太さ 0.6pt(上下中央揃え)
            - `medium`: セルは横 6mm × 縦 0.5mm，線の太さ 0.7pt(上下中央揃え)
            - `large`: セルは横 6.9mm × 縦 0.5mm，線の太さ 0.8pt(上下中央揃え)
        - 解答記入行: 空白とする。縦は 1fr とする。
            - `small`: セルは横 4.8mm
            - `medium`: セルは横 6mm
            - `large`: セルは横 6.9mm
- 最左桁は演算子列(+)とし，その右側に数字列を置く。数字列は被加数／加数の桁数の多いほうに合わせる。例えば被加数が3桁で，加数が2桁であれば，3桁確保する。1桁=横1セルとする。
- 問題はリージョンの右上に配置する。ただし，`--scale`` 指定に応じて余白を設定する。
    - `small`: 右側に3.6mm，上側に6mm
    - `medium`: 右側に4mm，上側に7mm
    - `large`: 右側に4.8mm，上側に8mm
- 問題番号はリージョンの左上付近(横位置はリージョン左側余白のすぐ右，縦位置は被加算数と同じセル位置の上揃え)に配置する。暗算と同様に丸数字。余白は問題本体の余白設定に従う。
- 問題の数字と演算子は全角とする。
