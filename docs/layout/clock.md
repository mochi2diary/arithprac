# 問題(時計) のレイアウト

役割: 時計形式の問題面レイアウト。用紙・共通事項および解答面は [CLAUDE.md](../../CLAUDE.md) / [answer.md](answer.md) を参照。英語での解答欄の差異は [i18n.md](../i18n.md) を参照。

## ページ・用紙

問題(暗算)と同一。

## A5 1枚(1回分)の構成 — `probset(title, left, right)`

上から順に:

1. **大見出し**: 中央揃え，18pt，太字(`weight: "bold"`)。文言は「時計マスター」。
2. `#v(3pt)` の空き。
3. **回・名前・得点の行**: 問題(暗算)と同様。
4. `#v(12pt)` の空き。
5. **問題本体**: 見出し以降の残り領域を，格子状の「リージョン」に等分割し，1 リージョンに 1 問を配置する。

## リージョン割り

- 問題(筆算)と同様に，問題(時計)でも問題本体用の領域をリージョンに分割し，1リージョンに1問を配置する。リージョン間に空白は発生しないようにする。
- 1回あたりのリージョン数(= 問題数)は問題(筆算)と同様に `-n` `--num N`(N: Integer) で指定する。時計問題の種別または各ステージでは `--num` 相当の指定を行う。

## リージョン内のレイアウト

リージョン内のレイアウトは，時計問題の種別によって異なる。

### 時計(よみ)

- リージョン数は `-n 4` とする。
- 問題番号はリージョンの左上付近に配置する。アナログ時計盤は丸形で問題番号とは重ならないように配置できるので，問題番号は時計盤と上下方向または左右方向で被ってもいいようにレイアウト設計する。
- 時計盤をリージョンの上側，左右中央に直径6cmで配置する。
- 解答欄をリージョンの下側，左右中央に配置する。
    - 解答欄の横幅は時計盤の横幅より左右とも5mmずつはみ出す，高さは18mm，線の太さ 0.7pt の角丸四角とし，角丸の半径は5mmとする。
    - 解答欄の中の字は ふん の有無で配置を変える。
        - 「ふん」がある場合は，解答欄の右側の角丸になりはじめるところより3mm右の位置を右端とし，解答欄の下端から3mm上が下端となるように，10pt で「ふん」と記載する。解答欄の中央より2mm左の位置を右端とし，解答欄の下端から3mm上が下端となるように，10pt で「じ」と記載する。
        - 「ふん」がない場合は，解答欄の右側の角丸になりはじめるところを右端とし，解答欄の下端から3mm上が下端となるように，10pt で「じ」と記載する。
    - 英語(`--lang en`)では解答欄の中の字が異なる。「多言語対応」の項に記載する。

### 時計(かき)

- リージョン数は `-n 6` とする。
- 問題番号の配置は よみ と同様とする。
- 時計盤をリージョンの下側，左右中央に配置する。
- 問題をリージョンの上側，左右中央に配置する。
    - 分 がない場合は，"数字 じ" と記載する。数字は 14pt で「じ」は 12pt とする。
    - 分 がある場合は，"数字 じ 数字 ふん" と記載する。数字は 14pt で「じ」「ふん」は 12pt とする。
