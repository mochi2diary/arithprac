## 解答 のレイアウト(暗算・筆算・時計よみ 共通)

問題ページの後に，`#set page` 規則で自動改ページして縦向きの新ページから始める。

### ページ・用紙

- `#set page(flipped: false, margin: (x: 10mm, y: 10mm))`
    - A4 縦(portrait)。マージンは左右・上下とも 10mm。
- 見出し: 中央揃え，16pt，太字。文言は "暗算マスター ステージ名 解答"。その後 `#v(6pt)`。
- 全 SETS 回分の解答ブロックを横に並べて配置: `grid(columns: (1fr × 列数), column-gutter: 3mm, row-gutter: <行間>)`(横に並べて1ページに多くの回を収める)。列数と行間は `--scale` 指定により異なる。
    - 2列パターンのスケール(`small` / `medium` / `large`): 横 4 列，行間 `6pt`。
    - 1列パターンのスケール(`onesmall`): 横 6 列，行間 `3pt`。解答ブロックが細く(1列)縦に長いため，横に多く並べ行間を詰める。
    - 列数は「ブロック幅 × 列数 + 隙間 3mm × (列数 - 1)」が A4 縦の使える幅(190mm)に収まる範囲とし，行間は解答ブロックの行が A4 縦の使える高さに収まるように定める。

### 1回分の解答ブロック — `ansblock(title, items, leftn)`

- `block(inset: (x: anspad, y: 6pt), radius: 2pt, stroke: 0.5pt, breakable: false)` の囲み。ブロック幅は内容に合わせて縮める(右側に余白を作らない)。
- 先頭に「第N回」— 太字，11pt。その後 `#v(3pt)`。
- 中身は問題と同様に 前半 / 後半 の縦 2 列: `grid(columns: (auto, anspad, anspad, auto), align: top)`。
    - 区切りの点線は問題と同じ(`dash: "dotted"`，`luma(140)`，0.6pt，`x: 2`)。
    - 左列に `leftn`(= 問題の `left_count`)問，右列に残りを置き，問題と対応させる。
    - 1列パターンでは `leftn` が全問数となり後半が空になるため，後半の列と区切りの点線を出さず，1 列で表示する。
- **すき間の均等化**: 共通すき間 `anspad = 2mm` を，ブロック左右の外側(`inset x`)と中央の点線まわり(グリッドの2列)に同じ幅で適用する。番号を左揃え・答えを右揃えにすることで，次の3箇所がすべて `anspad + セル内側 2pt` で等しくなる。
    - 枠の左線 ↔ 左の丸数字 / 点線 ↔ 右の丸数字 / 右の答え ↔ 枠の右線。

### 1問分の解答セル — `anscell(it)`

- 2 セルの表 `table(columns: (ansnumw, answ), stroke: none, inset: (x: 2pt, y: 1pt))`。列幅は `ansnumw = 6mm`(番号)，`answ`(答え)は `--scale` 指定により異なる。
    - 2列パターンのスケール(`small` / `medium` / `large`): `answ = 12mm`(最大4桁 9801 でも右揃えで収まる)。
    - 1列パターンのスケール(`onesmall`): `answ = 18mm`(小数の答えは最長9文字 = 約15.9mm となるため。横 6 列に並べられる幅とする)。
    1. 問題番号 丸数字(例: ①, ②, ③，⑳，㉑，㉖)— **左揃え**，解答文字サイズ `ansfs = 10pt`(人間が読みやすい固定サイズ)。
    2. 答え — **右揃え**，10pt。
- 番号は左揃え・答えは右揃えで縦位置をそろえる。
