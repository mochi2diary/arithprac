# 問題(暗算) のレイアウト

役割: 暗算形式の問題面レイアウト。用紙・共通事項および解答面は [CLAUDE.md](../../CLAUDE.md) / [answer.md](answer.md) を参照。

## ページ・用紙

- `#set page(paper: "a4", flipped: true, margin: (x: 6mm, y: 8mm))`
    - A4 横(landscape)。マージンは左右 6mm・上下 8mm。
- 1 ページ = A5 × 2枚(= 2回分)。`grid(columns: (1fr, 1fr), column-gutter: 10mm, setA, setB)` で左右に並べる。
- A4 横を左右に分ける中央の切り取り線: `place(top + center, ...)` で高さ 100% の縦線。破線 `dash: "dashed"`，色 `luma(150)`，太さ 0.6pt。
- 全体の本文フォント: `BIZ UDGothic`(定数 `JP_FONT`)，既定サイズ 12pt，`lang: "ja"`。

## A5 1枚(1回分)の構成 — `probset(title, left, right)`

上から順に:

1. **大見出し**: 中央揃え，18pt，太字(`weight: "bold"`)。文言は「暗算マスター」。
2. `#v(3pt)` の空き。
3. **回・名前・得点の行**: 中央揃え，10pt。
    - 「第N回」(`title`)，`#h(8mm)` の後に「名前」+ 幅 28mm の下線欄(`stroke: (bottom: 0.5pt)`)，`#h(4mm)` の後に「得点」+ 幅 14mm の下線欄。
4. `#v(8pt)` の空き。
5. **問題本体**: 2列パターンと1列パターン
    - 2列パターン
        - 前半(左)と後半(右)の 2 列。`grid(columns: (1fr, 1.5mm, 6mm, 1fr), align: top)`。
        - 左右の間の点線: `grid.vline(x: 2, ...)`，`dash: "dotted"`，色 `luma(140)`，太さ 0.6pt。線をやや左に寄せ，右列の問題番号との隙間を広めにとる(左 1.5mm / 右 6mm)。
    - 1列パターン
        - 前半/後半に分けず，全問を上から下へ1列に並べる。`grid(columns: (1fr), align: top)`。
        - 列間の点線は引かない。

## 1問分の行 — `probrow(n, a, b)`

1回あたりの問題数は，`--scale` 指定毎に以下の値を想定する。
    - `small`: 20問(10問×2列)
    - `medium`: 16問(8問×2列)
    - `large`: 10問(5問×2列)
    - `onesmall`: 15問(15問×1列)

- 2列パターン
    - 1 問を 6 セルの表で表す。列幅は `columns: (numw, valw, opw, valw, opw, auto)`，罫線なし(`stroke: none`)，縦中央揃え(`align: horizon`)。行間は `--scale`` 指定により異なる。
        - `small`: `inset: (x: 2pt, y: 10pt)`
        - `medium`: `inset: (x: 2pt, y: 11pt)`
        - `large`: `inset: (x: 2pt, y: 20pt)`
    - 列幅定数: `numw = 6mm`(番号)，`valw = 10mm`(被演算数・演算数。3桁でも右揃えで収まる)，`opw = 5mm`(演算子)。
    - 各セル:
        1. 問題番号 丸数字(例: ①, ②, ③，⑳，㉑，㉖)— 右揃え，12pt。
            - 左列の最上位が問題番号①で，左列を下に向かって順に②③…，左列の下までいったあと右列の最上位に移動し，右列を下に向かって順に進む。
        2. 第1項 `a` — 右揃え。フォントサイズは `--scale` 指定により異なる。
            - `small`: 13pt とする。
            - `medium`: 14pt とする。
            - `large`: 16pt とする。
        3. 演算子(加算なら `+`)— 中央揃え。フォントサイズは `--scale` 指定により異なる。
            - `small`: 12pt
            - `medium`: 13pt
            - `large`: 15pt
        4. 第2項 `b` — 右揃え。フォントサイズは第1項の数字(`a`)と同一値とする。
        5. 等号「=」— 中央揃え。フォントサイズは第1項の数字(`a`)と同一値とする。
        6. 解答欄 — `align(left + horizon)` に `ansbox` を配置。
    - 数値は右揃えで右端をそろえる(将来の桁数拡張に備える)。
    - **解答欄 `ansbox`**
        - `box(width: boxw, height: boxh, stroke: 0.7pt, radius: 1pt)`。
        - サイズは `--scale` 指定により異なる。
            - `small`: `boxw = 26mm`(横長の□)，`boxh = 9mm`(手書き用に本文より大きめ)。
            - `medium`: `boxw = 26mm`(横長の□)，`boxh = 12mm`(手書き用に本文より大きめ)。
            - `large`: `boxw = 26mm`(横長の□)，`boxh = 18mm`(手書き用に本文より大きめ)。
- 1列パターン
    - 問題(式)はフリーフォーマットとする。項数・桁数・演算子の種類が問題ごとに異なってよく，式を項や演算子ごとのセルに割り付けない。式全体を1つの文字列として組み，1セルに収める(`probrow(n, expr)`)。
    - 1 問を 4 セルの表で表す。列幅は `columns: (numw, 1fr, eqw, auto)`，罫線なし(`stroke: none`)，縦中央揃え(`align: horizon`)。行間は `--scale` 指定により異なる。
        - `onesmall`: `inset: (x: 2pt, y: 3pt)`
            - 1回あたりの問題数(15問)を A5 の高さに収めるための値とする。1問あたりの高さは 解答欄の高さ + 行間×2 となるので，A5 の使える高さ(見出しを除いて約170mm)を問題数で割った値を超えないようにする。
    - 列幅定数: `numw = 6mm`(番号)，`eqw = 5mm`(等号)。式の列は `1fr` とし，行の残り幅を吸収させる。
        - これにより等号と解答欄が行の右端にそろう(= と解答欄をまとめて右寄せ)。式は左揃えのままなので，全行で式の左端・等号・解答欄の位置が一致する。
    - `numgap = 5mm`: 問題番号と式のあいだの空き。式のセルの先頭に置く(番号は右揃えのまま，間隔だけが広がる)。
    - 各セル:
        1. 問題番号 丸数字(例: ①, ②, ③，⑳，㉑，㉖)— 右揃え，12pt。
            - 最上位が問題番号①で，下に向かって順に②③…と進む。
        2. 問題(式) — 左揃え(先頭に `numgap` の空き)。フォントサイズは `--scale` 指定により異なる。
            - 式中の数値と演算子の間には空白を入れる(例: `3 + 4`，`12 × 3 - 5`)。
            - `onesmall`: 12pt とする。
        3. 等号「=」— 中央揃え。フォントサイズは式(`expr`)と同一値とする。
        4. 解答欄 — `align(left + horizon)` に `ansbox` を配置。
    - 式は左揃えとする。式が式の列(`1fr`)に収まらない場合はプログラムの実行時処理としては列幅を超えてはみ出してよい(エラーとはしない)が，はみ出ないようにプログラムを修正すべきである。
    - **解答欄 `ansbox`**
        - `box(width: boxw, height: boxh, stroke: 0.7pt, radius: 1pt)`。
        - サイズは `--scale` 指定により異なる。
            - `onesmall`: `boxw = 70mm`(1列ぶんの幅を活かした横長の□)，`boxh = 9mm`(手書き用に本文より大きめ)。

## 前半/後半の振り分け

- 2列パターンでは，1回 `num` 問を，前半(左)= `left_count(num)` = `(num + 1) / 2` 問(奇数なら左が1問多い)，残りを後半(右)に置く。
- 1列パターン(`onesmall`)では振り分けを行わず，`num` 問すべてを1列に置く(`left_count(num)` = `num` として扱う)。
