# 多言語対応

役割: 多言語対応(言語切替の方針，紙面文言・ステージサブタイトル・日本語と構造が変わる箇所)。CLAUDE.md から `@import` され常時ロードされる。

- 使用言語は起動時オプション `--lang` で指定する。指定がない場合はデフォルトの `ja` が使用される。
- プログラム中の言語依存の定数は一カ所に集約する。定数 `TEXTS`(`{ja: {...}, en: {...}}`)に置き，コード中の他の場所には日本語・英語の文言を直接書かない。取り出しは `t(:key, **args)` で行い，可変部分は `%{name}` 形式で埋める。
- 現時点でフォントは ja|en 両方とも `BIZ UDGothic` を使用する。
- 対応範囲は「画面に出る文言」(使い方・エラー・警告・進捗)と「紙面(PDF)に出る文言」の両方とする。ソースコードのコメント，および生成される `.typ` 内のコメントは利用者向けの出力ではないため，言語によらず日本語のままとする。
- `--lang` は使い方(`--help`)やエラーメッセージの言語も切り替えるため，`OptionParser` を組み立てる前に `ARGV` から先読みする。先読みで拾えるのは完全な形の指定(`--lang en` / `--lang=en`)のみで，省略形(`--lan en` など)は `parse!` の後に反映する。
    - `--lang` の値が不正な場合のエラーは，先読みの段階で検出するためデフォルト言語(`ja`)で表示される。

| 用途 | ja | en |

| 大見出し(筆算) | 筆算マスター | Written Calc Master |
| 大見出し(時計) | 時計マスター | Clock Master |
| 回の見出し | 第N回 | Set N |
| 名前欄 | 名前 | Name |
| 得点欄 | 得点 | Pts |
| 解答ページの見出し | (大見出し) (ステージ名) 解答 | (大見出し) - (ステージ名) - Answers |

| S1-2-1〜S1-2-2 | ひきざん暗算1〜2 | Mental Sub 1〜2 |
| S1-3-1〜S1-3-6 | かけざん暗算1〜6 | Mental Mul 1〜6 |

| S1-8-1 | 小数かけざん暗算1 | Mental Decimal Mul 1 |
| S2-1-1〜S2-1-5 | たしざん筆算1〜5 | Column Add 1〜5 |

- サブタイトルは「回・名前・得点の行」に収める必要がある。この行で使える幅はおよそ 47mm(10pt)であるため，英語のサブタイトルは 23 文字程度までとし，収まらないものは短縮形とする(例: `Mental Decimal Mul 1`)。

## 日本語と構造が変わるところ

- 時計(よみ)の解答は，日本語では数字と単位で書く(例: `3 じ 15 ふん`)が，英語では数字ではなく英単語で書き，単位にあたる語は入れない。
    - 「○○じ」の場合は `three o'clock` と書く。
    - 「○○じ△△ふん」の場合は `three fifteen` のように「じ」「ふん」にあたる数を並べて書く。
        - ふんが1桁(1〜9)の場合は，英語の読みに合わせて `three oh five` のように `oh` を入れる。
    - 「0 じ」は，日本語では「12 じ」とも読めるため `0 じ(12 じ)` と併記するが，英語には 0 時の読みが無いため `twelve` とだけ書く(併記しない)。
- 時計(よみ)の解答欄は，日本語では角丸四角の中に単位(「じ」「ふん」)を置くが，英語では角丸四角を描かず，`It is`(左)と `．`(右)のあいだに下線を1本引く。「ふん」の有無で置き方を変えない。
    - 解答欄が占める幅と高さは日本語と同じとする(角丸四角を描かないだけで寸法は変えない)。文字の左右の位置も，角丸四角があるものとして日本語と同じ基準から測る。
    - `It is`・下線・`．` の下端は，いずれも解答欄の下端から 8mm 上とする(日本語の「じ」「ふん」の位置より 5mm 上)。
    - `It is` は，文字列の左端が角丸四角の直線になりはじめるところより 3mm 左となる位置に，10pt で記載する。
    - `．` は，文字列の右端が角丸四角の丸くなりはじめるところより 3mm 右となる位置に，12pt で記載する。見やすさのため全角とする。
    - 下線は，`It is` の右端と `．` の左端からそれぞれ 2mm 空けて引く。線の太さは角丸四角の線と同じ 0.7pt とする。
- 英語では `o'clock` のアポストロフィが日本語フォントの全角の約物に置き換わり前後に空きができるため，Typst 側で `#set smartquote(enabled: false)` を指定する(日本語の紙面には影響しない)。
- 筆算の数字と演算子は，言語によらず全角のままとする(半角より字形が広く字間が行間と釣り合う，というレイアウト上の理由によるため)。
- 上記以外の寸法(用紙・リージョン・解答欄・フォントサイズ)は言語によらず同一とする。時計の解答欄の幅は，日本語の最長の解答(`0 じ(12 じ) 55 ふん`)を基準とした値をそのまま使う(英語の最長の解答 `twelve twenty-seven` も同じ 33.5mm で収まる)。
- 画面に出るメッセージは，上記以外は日本語の文言をそのまま英訳したものとする(意味・情報量は変えない)。
