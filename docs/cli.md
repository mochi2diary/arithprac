# CLIオプション

役割: CLIオプション・生成/出力の定数・出力処理の仕様。CLAUDE.md から `@import` され常時ロードされる。

以下のCLIオプションを受け付ける(Gemは `optparse` を使用)。

- `-s S`, `--stage S`(String): ステージ名。
    - ステージ名指定が行われた場合は，`--num` `--pattern` `--ratio` の指定は無視される。
    - ステージ名は case-insensitive とする。指定されたステージ名が存在しない場合はエラーとする。
- `-p P`, `--pages P`(Integer): 生成する問題のページ数。1ページあたり2回分が含まれるので，生成される問題は `2 * P` 回分となる。`P` のデフォルト値は `DEFAULT_PAGES`(10)。指定値が0以下の場合はエラーとする。
- `--stage-list`: ステージ名(例: S1-1-1)とサブタイトル(例: たしざん暗算1)の対応の一覧とを表示して終了。
- `--num N`(Integer): 1回あたりの問題数。
    - `N` の範囲は 暗算のパターンを指定した場合は `MIN_PROBLEMS`(2)〜`MAX_PROBLEMS`(26)，デフォルト値は `DEFAULT_PROBLEMS`(20)。筆算のパターンを指定した場合は 12/8/6/4/1 のいずれか。範囲外の場合は `abort` で終了。
- `--pattern P`(String): 問題パターン名(例: P1-1-1)。複数指定可。指定が行われた場合は `--stage` 指定が無視される。
    - 問題パターン名は case-insensitive とする。指定されたパターン名が存在しない場合はエラーとする。
- `--ratio R`(Rational): 指定されたパターンの混合比率。`--ratio` オプションを指定する場合は，`--pattern` で指定されたパターンの数と同じ数だけ指定する必要がある。ただし，指定されたRational値の合計が1にならない場合(加算処理はRationalで行う)は，合計が1になるように正規化される。`--pattern` オプションが指定されたが `--ratio` が指定されなかった場合は，指定されたパターンの数だけ等しい比率で割り当てられる。
    - OptionParser.acceptでRationalを定義し，引数をRationalとして扱う。
    - 負の数が指定された場合，または指定値の合計が0になった場合はエラーとする。
    - 実際の問題数への丸め方は，
        - まず各パターンに `(指定比率 * 問題数).truncate` の値(整数)だけ問題数を割り当てる。
        - 未割り当ての問題数がある場合は，
            - 各パターンのその時点での `(指定比率 * 問題数) - 割り当て済み問題数` の値を計算し，その値が正になるパターンのみを対象として，その値の比率を各々の確率として，1つの問題をどれかのパターンに割り当てる。
            - これを未割り当ての問題数がなくなるまで繰り返す。
- `--scale S`(String): 文字および解答欄サイズの指定。`S` は `small` / `medium` / `large` / `onesmall` のいずれか(case insensitive)。デフォルトは `small`。`onesmall` は暗算形式のみで使用できる1列レイアウト(筆算形式と組み合わせた場合はエラーとする)。各指定値に対するレイアウトは印刷イメージの項に記載。
    - 筆算形式では，リージョン内の文字サイズ・桁幅の指定として `--num` とは独立に扱う(リージョン数が少ないからといって必ずしも文字サイズを大きくするわけではない)。
- `-o O`, `--output O`(String): 出力ファイル名。拡張子は `.pdf` とする。指定された文字列が `.pdf` で終わっていないファイル名(= 拡張子がPDFではない)の場合は，定数 `BASENAME` に `.pdf` を付けたものを使用する。なお，途中で生成される `.typ` ファイルは，出力ファイル名の拡張子を `.typ` に置き換えたものを使用する。
- `--lang L`(String): 使用言語。`L` は `ja` / `en` のいずれか(case insensitive)。デフォルトは `ja`。
- `--seed S`(Integer): 乱数シード(再現用)。指定時は `srand(seed)` を実行。
- `-h`, `--help`: 使い方を表示して終了。

## 生成・出力に関する定数(コード内固定値。必要ならオプション化を検討)

- `SETS = 10`: 回数(A5 の枚数)。問題は 2 回分ずつ A4 横 5 ページ，解答は A4 縦 1 ページ。
- `JP_FONT = 'BIZ UDGothic'`: 使用フォント。
- `BASENAME = 'arithprac'`: 出力ファイル名の基底。`arithprac.typ` を生成後，`typst compile` で `arithprac.pdf` を生成する。

## 出力

- `.typ` を書き出し，`system('typst', 'compile', typ_path, pdf_path)` で PDF 化。成功時は `pdfinfo` でページ数を表示，失敗時は警告して `exit 1`。
