# ステージ: 時計-よみ(S3-1-x)

役割: 時計(よみ)のステージ定義。参照するパターンは [p4-1-read.md](p4-1-read.md)。索引は [CLAUDE.md](../../../CLAUDE.md)。

- よみ1(S3-1-1)
    - 1回あたり4問，同一の問題は各回あたり2回以上出題されない。
    - P4-1-1: 4問
- よみ2(S3-1-2)
    - 1回あたり4問，同一の問題は各回あたり2回以上出題されない。
    - P4-1-1: 1問
    - P4-1-2: 3問
    - ただし「1回」あたり，全問を通じて同一の「ふん」は「じ」が異なっても2回以上出題されない(つまり，S3-1-2では15/30/45が1回ずつ出題される)。また，同一の「じ」は「ふん」が異なっても2回以上出題されない。
- よみ3(S3-1-3)
    - 1回あたり4問，同一の問題は各回あたり2回以上出題されない。
    - P4-1-2: 1問
    - P4-1-3: 3問
    - ただし「1回」あたり，全問を通じて同一の「ふん」は「じ」が異なっても2回以上出題されない。また，同一の「じ」は「ふん」が異なっても2回以上出題されない。
- よみ4(S3-1-4)
    - 1回あたり4問，同一の問題は各回あたり2回以上出題されない。
    - P4-1-1/P4-1-2/P4-1-3: 1問(各パターンは等確率)
    - P4-1-4: 3問
    - ただし「1回」あたり，全問を通じて同一の「ふん」は「じ」が異なっても2回以上出題されない。また，同一の「じ」は「ふん」が異なっても2回以上出題されない。
