# パターン: 筆算-減算(P2-2-x)

役割: 筆算(減算)の単問パターン定義。関連ステージは [s2-2-sub.md](s2-2-sub.md)。索引は [CLAUDE.md](../../../CLAUDE.md)。

以下で「○の位の繰り下がり」とは，○の位の数値を1つ減らしてその1つ下の位の数値を10増やすような計算上のオペレーションを指す。例えば，「67 - 8 = □」では，十の位を6から5に減らし，1の位を8から18に増やすような計算上のオペレーションが必要であるため「十の位の繰り下がりあり」と呼ぶ。

- P2-2-1: 被減数 2桁，減数 1桁(0以外)，結果 2桁(繰り下がりなし)
    - 例1: 17 - 3 = □
    - 例2: 45 - 5 = □
- P2-2-2: 被減数 2桁，減数 1桁(0以外)，結果 2桁(十の位の繰り下がりあり)
    - 例1: 87 - 8 = □
    - 例2: 41 - 2 = □
- P2-2-3: 被減数 3桁，減数 2桁，結果 3桁(百の位の繰り下がりなし，十の位の繰り下がりなし)
    - 例1: 145 - 22 = □
    - 例2: 173 - 61 = □
- P2-2-4: 被減数 3桁，減数 2桁，結果 3桁(百の位の繰り下がりなし，十の位の繰り下がりあり)
    - 例1: 145 - 28 = □
    - 例2: 173 - 65 = □
- P2-2-5: 被減数 3桁，減数 2桁，結果 2桁(百の位の繰り下がりあり，十の位の繰り下がりなし)
    - 例1: 145 - 74 = □
    - 例2: 132 - 61 = □
- P2-2-6: 被減数 3桁，減数 2桁，結果 2桁(百の位の繰り下がりあり，十の位の繰り下がりあり)
    - 例1: 145 - 78 = □
    - 例2: 132 - 65 = □
- P2-2-7: 被減数 3桁，減数 3桁，結果 3桁(百の位の繰り下がりなし，十の位の繰り下がりなし)
    - 例1: 345 - 231 = □
    - 例2: 768 - 547 = □
- P2-2-8: 被減数 3桁，減数 3桁，結果 3桁(百の位の繰り下がりなし，十の位の繰り下がりあり)
    - 例1: 315 - 206 = □
    - 例2: 768 - 519 = □
- P2-2-9: 被減数 3桁，減数 3桁，結果 2～3桁(百の位の繰り下がりあり，十の位の繰り下がりなし)
    - 例1: 345 - 174 = □
    - 例2: 768 - 685 = □
- P2-2-10: 被減数 3桁(下2桁は00でない)，減数 3桁，結果 2～3桁(百の位の繰り下がりあり，十の位の繰り下がりあり)
    - 例1: 345 - 177 = □
    - 例2: 760 - 685 = □
- P2-2-11: 被減数 3桁(下2桁が00)，減数 3桁，結果 2～3桁(百・十の位の繰り下がりあり)
    - 例1: 300 - 177 = □
    - 例2: 700 - 685 = □
- P2-2-12: 被減数 4桁，減数 3～4桁，結果 4桁(千の位の繰り下がりなし，百・十の位の繰り下がりはあってもなくてもよい)
    - 例1: 1345 - 278 = □
    - 例2: 5768 - 445 = □
- P2-2-13: 被減数 4桁，減数 3～4桁，結果 3～4桁(千の位の繰り下がりあり，百・十の位の繰り下がりはあってもなくてもよい)
    - 例1: 7345 - 5628 = □
    - 例2: 4768 - 3845 = □
- P2-2-14: 被減数 4桁(下3桁は000でない)，減数 3～4桁，結果 3～4桁(千・百・十の位の繰り下がりあり)
    - 例1: 7345 - 5648 = □
    - 例2: 5123 - 3845 = □
- P2-2-15: 被減数 4桁(下3桁が000)，減数 2～4桁，結果 2～4桁(千・百・十の位の繰り下がりあり)
    - 例1: 8000 - 7628 = □
    - 例2: 5000 - 3845 = □
    - 例3: 3000 - 2975 = □
