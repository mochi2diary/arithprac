# パターン: 筆算-加算(P2-1-x)

役割: 筆算(加算)の単問パターン定義。関連ステージは [s2-1-add.md](s2-1-add.md)。索引は [CLAUDE.md](../../../CLAUDE.md)。

- P2-1-1: 被加数 2桁，加数 1桁(0以外)，結果 2桁(繰り上がりなし)
    - 例1: 12 + 3 = □
    - 例2: 45 + 4 = □
    - 適合しない例: 95 + 5 = □
- P2-1-2: 被加数 2桁，加数 1桁(0以外)，結果 2桁(百の位への繰り上がりなし，十の位への繰り上がりあり)
    - 例1: 12 + 8 = □
    - 例2: 45 + 7 = □
    - 適合しない例: 95 + 7 = □
- P2-1-3: 被加数 2桁，加数 2桁，結果 2桁(百の位への繰り上がりなし，十の位への繰り上がりなし)
    - 例1: 12 + 34 = □
    - 例2: 45 + 22 = □
    - 適合しない例: 67 + 34 = □
- P2-1-4: 被加数 2桁，加数 2桁，結果 2桁(百の位への繰り上がりなし，十の位への繰り上がりあり)
    - 例1: 12 + 39 = □
    - 例2: 45 + 27 = □
    - 適合しない例: 67 + 32 = □
- P2-1-5: 被加数 2桁，加数 2桁，結果 3桁(百の位への繰り上がりあり，十の位への繰り上がりはあってもなくてもよい)
    - 例1: 67 + 34 = □
    - 例2: 45 + 78 = □
    - 例3: 86 + 22 = □
- P2-1-6: 被加数 3桁，加数 2桁，結果 3桁(千の位への繰り上がりなし，百および十の位への繰り上がりはあってもなくてもよい)
    - 例1: 123 + 45 = □
    - 例2: 456 + 78 = □
    - 適合しない例: 966 + 45 = □
- P2-1-7: 被加数 3桁，加数 2桁，結果 4桁(千の位への繰り上がりあり，百および十の位への繰り上がりはあってもなくてもよい)
    - 例1: 966 + 43 = □
    - 例2: 956 + 78 = □
- P2-1-8: 被加数 3桁，加数 3桁，結果 3桁(千の位への繰り上がりなし，百および十の位への繰り上がりはあってもなくてもよい)
    - 例1: 123 + 456 = □
    - 例2: 234 + 567 = □
- P2-1-9: 被加数 3桁，加数 3桁，結果 4桁(千の位への繰り上がりあり，百および十の位への繰り上がりはあってもなくてもよい)
    - 例1: 123 + 894 = □
    - 例2: 876 + 567 = □
