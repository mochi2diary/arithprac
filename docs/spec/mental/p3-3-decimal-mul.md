# パターン: 暗算-小数乗算(P3-3-x)

役割: 暗算(小数乗算)の単問パターン定義と，小数に関する用語定義。関連ステージは [s1-8-decimal-mul.md](s1-8-decimal-mul.md)。索引は [CLAUDE.md](../../../CLAUDE.md)。

小数に関連して以下の用語定義を行う。

- 便宜上，本プログラムでは小数について10進数での科学記数法での仮数部・指数部のことを「仮数部」「指数部」と呼び，仮数部の10進数での有効桁数を「仮数部桁数」と呼ぶこととする。
    - 例: 1.6 = 1.6 × 10^0 → 仮数部は 1.6 で，指数部は 0 (10^0 == 1)，仮数部桁数は 2
    - 例: 16 = 1.6 × 10^1 → 仮数部は 1.6 で，指数部は 1 (10^1 = 10)，仮数部桁数は 2
    - 例: 0.016 = 1.6 × 10^-2 → 仮数部は 1.6 で，指数部は -2 (10^-2 = 0.01)，仮数部桁数は 2
    - 例: 9 = 9 × 10^0 → 仮数部は 9 で，指数部は 0 (10^0 = 1)，仮数部桁数は 1
- 本プログラムでは，仮数部の下のほうの桁が 0 になることを「ゼロ発生」と呼ぶこととし，そのゼロの連続桁数を「ゼロ発生桁数」と呼び，ゼロ発生があったときは仮数部の桁数が減ったものとして扱う。
    - 例: 0.15 × 0.6 = 0.09 → 結果の仮数部は 9，ゼロ発生あり，ゼロ発生桁数1，結果の仮数部桁数は 1
    - 例: 0.025 × 40 = 1 → 結果の仮数部は 1，ゼロ発生あり，ゼロ発生桁数2，結果の仮数部桁数は 1
    - 例: 0.125 × 0.08 = 0.01 → 結果の仮数部は 1，ゼロ発生あり，ゼロ発生桁数3，結果の仮数部桁数は 1
    - 例: 0.4 × 0.2 = 0.08 → 結果の仮数部は 8，ゼロ発生なし，結果の仮数部桁数は 1
- 本プログラムでは，10進数での科学記数法のことを「浮動小数点表記」と呼び，算数で使用する小数の表記法のことを「固定小数点表記」と呼ぶ。
    - 例: 1.5×10^-2 → 浮動小数点表記，0.015 → 固定小数点表記
- 本プログラムでは，固定小数点表記したときに小数点以下に桁を持つ(= 整数でない)ことを「小数点以下の桁あり」と呼ぶ。
    - 例: 1.4 → 小数点以下の桁あり，0.06 → 小数点以下の桁あり，14 → 小数点以下の桁なし
- パターン共通の制約として，
    - 仮数部桁数1の場合に，仮数部 1 は出現しない。

パターンを [被乗数，乗数，結果] で記載。

指数部の範囲も必要に応じて [被乗数，乗数，結果] で記載。範囲を ～ 表記する場合，～ の左辺値と右辺値を範囲に含む。指数は整数のみ。範囲は 0 に近い側を左辺値として書く(例: `-1～-3`，`0～4`)。
