# ステージ: 暗算-減算(S1-2-x)

役割: 暗算(減算)のステージ定義。参照するパターンは [p1-2-sub.md](p1-2-sub.md)。索引は [CLAUDE.md](../../../CLAUDE.md)。

- ひきざん暗算1(S1-2-1)
    - 1回あたり10問，同一の問題は各回あたり2回以上出題されない。スケールは `large`。
    - P1-2-1: 10問
    - ただし「1回」あたり，全問を通じて 減数への 1 の出現回数を最大で 1 とし，被減数への 10 の出現回数を最大で 2 とする。また，答えが 0 になる(被減数 == 減数) 問題の出現回数を最大で 1 とする。調整方法はS1-1-1と同様とする。
- ひきざん暗算2(S1-2-2)
    - 1回あたり10問，同一の問題は各回あたり2回以上出題されない。スケールは `large`。
    - P1-2-1: 2問
    - P1-2-2: 8問
    - ただし「1回」あたり，全問を通じて 減数への 1 の出現回数を最大で 1 とし，また，答えが 0 または 10 になる(被減数 == 減数 または 被減数 - 減数 == 10)問題の出現回数を最大で 1 とする。調整方法はS1-1-1と同様とする。
