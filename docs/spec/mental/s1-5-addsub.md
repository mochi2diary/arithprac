# ステージ: 暗算-加減算(S1-5-x)

役割: 暗算(加減算混合)のステージ定義。参照するパターンは [p1-1-add.md](p1-1-add.md) / [p1-2-sub.md](p1-2-sub.md)。索引は [CLAUDE.md](../../../CLAUDE.md)。

- たしひき暗算1(S1-5-1)
    - 1回あたり10問，同一の問題は各回あたり2回以上出題されない。スケールは `large`。
    - P1-1-3: 2問
    - P1-1-6: 3問
    - P1-2-1: 2問
    - P1-2-2: 3問
    - ただし「1回」あたり，全問を通じて被加数・加数 または 減数に 1 が出現する回数を最大で 1 とし，被減数への 10 の出現回数を最大で 1 とする。また，ひきざんで答えが 0 または 10 になる(被減数 == 減数 または 被減数 - 減数 == 10)問題の出現回数を最大で 1 とする。調整方法はS1-1-1と同様とする。
